# 人形机器人运动智能知识库

> 出品：具身智能研究室

这个知识库围绕人形机器人运动智能的完整研发链组织内容，帮助读者把单篇论文、开源项目、公司动态和岗位要求放回同一张问题地图中。

## 使用方法

建议先将仓库克隆到本地，让Agent能够检索完整目录、论文解读和项目记录：

```bash
git clone https://github.com/RealXiaoze/humanoid-motion-intelligence.git
cd humanoid-motion-intelligence
```

- **刚入门，不知道从哪里开始**：让Agent先阅读本页和[技术路线总览与学习路径](技术路线/README.md)，再提供你的专业背景、已有基础、可用硬件、目标岗位和学习周期。可以要求它给出分阶段学习路线，并说明每一阶段应该理解的问题、阅读的论文、可复现项目和验收结果。
- **正在开发运动控制算法，但暂时没有优化思路**：告诉Agent当前机器人、仿真平台、观测、动作、奖励、训练现象和实机问题，再让它阅读对应技术路线、[论文总索引](论文与项目/README.md)及相关`Pxxx`解读页。要求它比较相邻工作的设计差异，提出能够通过消融实验验证的改进方向，而不是只罗列算法名称。
- **正在准备实习、校招或社招**：进入[招聘与内推信息](求职与岗位/README.md)，查看面经、秋招问答和当前收录的招聘渠道。也可以让Agent根据目标岗位对照你的项目经历，整理能力缺口、项目表达重点和面试准备顺序；招聘状态和联系方式仍需回到原始页面再次确认。

使用Agent时，建议要求它在结论中注明引用的页面、稳定ID和原始来源。涉及论文结果、项目能力、公司动态和招聘状态的判断，应以原始材料为准。

## 六条技术路线

| 路线 | 主要回答的问题 |
|---|---|
| [动作数据与重定向](技术路线/01_动作数据与重定向.md) | 人体、视频或其他本体的动作怎样变成机器人可用参考和训练数据 |
| [Locomotion与运动先验](技术路线/02_Locomotion与运动先验.md) | 怎样形成基础移动、复杂地形适应、动作先验和行为模型 |
| [动作跟踪与全身控制](技术路线/03_动作跟踪与全身控制.md) | 怎样稳定执行参考动作，并处理失配、恢复和人体实时驱动 |
| [LocoManip](技术路线/04_LocoManip.md) | 怎样协同移动、接触和操作，改变物体或场景状态 |
| [世界模型、VLA与Agent](技术路线/05_世界模型VLA与Agent.md) | 怎样预测变化、生成动作、调用技能并完成长时任务 |
| [工程与实机部署](技术路线/06_工程与实机部署.md) | 怎样把算法接入本体、仿真、控制、安全评测和真实部署 |

## 阅读与使用

- 技术方法按最终解决的问题分类，AMP、Mimic、Diffusion、Transformer和世界模型等保留为方法标签。
- 公司自述、论文结果和第三方证据不能相互替代；公司目录与事件时间线均不构成强弱排名或投资建议。
- 招聘、薪资和产品信息会变化，使用前请检查页面日期和原始来源。
- 发现错误时，请提供具体页面、稳定ID和原始来源；转载与图片使用请先阅读[许可与版权边界](LICENSE.md)。
